A faster, quieter GitHub. Pull requests, issues, commits and checks, grouped by who acts next.

GitHub splits a pull request by record type: Conversation, Commits, Checks, Files. None of those tabs tells you whether it is your turn, so you work it out again on every visit. GitQuiet redraws fourteen pages on github.com itself and groups the same data by who acts next. Every action goes back through GitHub's own routes.

WHAT YOU GET
• Working set - every pull request you are in, across repositories, in four groups: Your Move, Waiting, Running, Settled
• Pull request review - unresolved threads, failing checks and commits pushed since you last looked, all above the diff
• Keyboard driven - walk threads, checks and files one key at a time
• Issues, Actions, commits and repository home follow the same grouping
• Runs inside GitHub's own interface, with Primer tokens and Octicons

WHY INSTALL
Stop working out what is waiting on you. Install GitQuiet, open a pull request on github.com, and read the list.

PRIVACY
No separate login. GitQuiet uses the GitHub session you already have, and your code and reviews stay in your browser. No analytics and no remote code.
