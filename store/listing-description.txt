A faster, quieter GitHub. Pull requests, issues, commits and checks, grouped by who acts next.

Nothing on a GitHub page tells you whether it needs you, so you work it out again on every visit. GitQuiet is its own interface on the same data, and it files everything by what needs you. It opens on the addresses you already use, and every action goes back through GitHub's own routes.

WHAT YOU GET
• Working set - every pull request you are in, across repositories, in four groups: Needs You, Waiting, Running, Settled
• Pull request review - unresolved threads, failing checks and commits pushed since you last looked, all above the diff
• Keyboard driven - walk threads, checks and files one key at a time
• Issues, Actions, commits and repository home follow the same grouping
• Drawn in Primer tokens and Octicons, so it follows the theme you have

WHY INSTALL
Stop working out what is waiting on you. Install GitQuiet, open a pull request, and read the list.

PRIVACY
No separate login. GitQuiet uses the GitHub session you already have, and your code and reviews stay in your browser. No analytics and no remote code.
