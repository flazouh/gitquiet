The pull request number: ten places to put it

Every card below is the real header at the width of the screenshot, in the GitHub dark pack. Each option is drawn twice: once with the title as it came, once with a title long enough to run out of room, because that is the case that decided the current position.

What any answer has to keep

1. The number cannot live inside the element that truncates. It rode at the end of the heading once, and on a long title it was the first thing cut, down to #2….

2. It has to land in the same place on every pull request, so it can be found without reading the line.

3. It is the fact a reader says out loud and pastes into a message, so it cannot be so quiet that it has to be hunted for.

1. Today: a filled chip at the heading's size

Three filled objects on one line, and the second heaviest thing on the card is a number. The badge and the chip carry the same weight, so the eye reads badge, badge, then title.
