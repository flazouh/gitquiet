gitquiet privacy policy

Last updated: 11 August 2026

GitQuiet is a Chrome extension that improves GitHub pull request, issue, and Actions pages in your browser.

What we process

GitQuiet reads GitHub pages and API responses in your signed-in browser session so it can show review screens. That content stays in your browser.

GitQuiet stores display settings and a local cache of GitHub payloads in Chrome storage on your device so pages open quickly.

What we do not do

  • We do not sell user data.
  • We do not use your GitHub content for advertising.
  • We do not use your data for credit or lending decisions.

Optional error reporting

If error reporting is enabled in a given build, crash details may be sent to Sentry so we can fix bugs. Builds without a Sentry DSN send nothing.

Contact

Questions: open an issue on GitHub.
